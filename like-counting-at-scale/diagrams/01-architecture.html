Write Once, Count Everywhere

Every edge names its mechanism on purpose: the toggle write is conditional and idempotent, the counter write is an atomic Redis INCR with no lock to contend for, and the durable count only ever moves in batches, off the request path. The dashed line is the one fallback that matters: if Redis is down, the toggle still succeeds and the count read degrades to the durable store instead of failing.
